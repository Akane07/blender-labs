# Шпаргалка к защите — Лаба 8 «Простое моделирование» (Blender)

## Как устроен файл

- `Лаба8_Blender.blend` — 5 **сцен** (переключаются справа вверху, поле «Сцена»). Они заменяют файлы .max из методички:

| Сцена | Что внутри | Аналог из методички |
|---|---|---|
| 1 — Чашка (стандартные примитивы) | стенка, дно, 3 тора | Задание «Чашка» (Tube + Cylinder + 3 Torus) |
| 2 — Лоскутные сетки (задание 1) | Quad / Tri сетки + сглаживание, NURBS-поверхность | Quad Patch, Tri Patch, HSDS |
| 3 — Амортизатор Damper (задание 2) | амортизатор между двумя опорами, анимация 0–80 | ЛР13_2.max |
| 4 — Пружина Spring (задание 3) | пружина между основанием и грузом, 4 формы сечения | ЛР13_3.max |
| 5 — ИДЗ «Дом» | стены, дверь, окна, лестница, крыша, деревья, изгородь | Фамилия_№гр_ИДЗ_13.max |

- После переключения сцены курсор на 3D-окно → **Home** (показать всё).
- Скрытые коллекции «Этапы … (скрыто)» — модель на промежуточных шагах и образцы деревьев. Включаются глазом в аутлайнере.
- В каждой сцене своя камера и свет: **F12** сразу даёт кадр. В сценах 3 и 4 есть анимация — **пробел** (воспроизвести), Shift+← (в начало).
- Модификаторы **не применены** — все параметры можно крутить. Сломал — Ctrl+Z.

## Главная мысль (скажи первой)

В Blender нет трубы, лоскутных сеток, Damper, Spring и архитектурных объектов. Их заменяют **примитив + модификаторы** (вкладка с гаечным ключом), **ограничители** (вкладка «Ограничители») и **геометрические ноды**. Параметры при этом остаются живыми, как в 3ds Max.

## Сцена 1 — чашка

- «Стенка (Tube…)» → «Модификаторы» → **«Объёмность»**: «Толщина» 0,3 = R1 − R2, «Смещение» −1 (внутрь). Покрути «Толщину» — стенка толще/тоньше. Выключи модификатор (значок экрана) — останется труба без толщины.
- Почему не Tube: трубы нет. Цилиндр создан с «Тип заполнения оснований» = «Ничего».
- «Дно (Cylinder…)» — обычный цилиндр R 3,8, H 0,4.
- «Ободок» и «Кольцо у дна» — торы, «Основной радиус» 3,85, «Малый» 0,2 и 0,25.
- «Ручка» — тор, повёрнут на 90° по X; Tab — видно, что половина вершин удалена (у тора Blender нет Slice).
- Этапы: коллекция «Этапы чашки (скрыто)» — стенка → + дно → + торы.

## Сцена 2 — лоскутные сетки

- «Quad Patch — сетка 4×4» → модификатор **«Подразделение поверхности»** (аналог HSDS).
- «Tri Patch — сетка 4×4» → **«Триангулировать»** («Фиксировано») + «Подразделение поверхности».
- Включи «Наложения» → «Каркас» (или Z → «Каркас»): у квадратной сетки ровные клетки, у треугольной — «звёзды» и перекос. Это и есть разница Quad/Tri после HSDS.
- Покрути «Уровни - Вьюпорт» (0…3) — сетка гуще/реже.
- «NURBS-поверхность» — настоящая «лоскутная» поверхность Blender: Tab → двигай управляющие точки (G), поверхность гнётся плавно.

## Сцена 3 — амортизатор (Damper)

- Части: «основание (Base)», «корпус (Main)», «поршень (Piston)», «кожух (Boot)». Опоры: «Нижняя опора (Pick Base Object)», «Верхняя опора (Pick Piston Object)».
- Нажми **пробел**: верхняя опора двигается — поршень входит в корпус, амортизатор наклоняется, кожух сжимается.
- Или останови и сам двигай «Верхняя опора» (G) — то же самое вживую.
- Где настройка: выдели «основание» → вкладка **«Ограничители»**: «Копировать положение» (← нижняя опора) + «Слежение с амортизацией» (→ верхняя опора, ось Z). У поршня — наоборот. У кожуха — **«Растяжение»** до пустышки «Верх корпуса».
- Fillet 1/2 = модификатор **«Фаска»** на корпусе («Величина», «Сегменты»).
- Boot → Enable = глаз у «кожуха» в аутлайнере.
- Free Damper / Pin-to-Pin Height = двигай верхнюю опору только по Z (G Z).

## Сцена 4 — пружина (Spring)

- Выдели «Пружина (круглое сечение…)» → «Модификаторы» → **«Винт»**:
  - **«Итераций» = Turns** (8). Поставь 12 — витков больше, длина та же (за это отвечает драйвер).
  - **«Угол»** 360° = CCW (против часовой); −360° = CW.
  - Поле «Винт» фиолетовое — это **драйвер**: ПКМ → «Редактировать драйвер» → выражение `dist / turns`, `dist` — «Расстояние» между основанием и грузом.
- Пробел — груз прыгает, пружина сжимается/растягивается/наклоняется. Или двигай «Груз» сам.
- Wire Shape: коллекция «Формы сечения…» — круглое, прямоугольное, полукруглое (форма профиля), четвёртая — по часовой. Tab на любой — видно маленький профиль, который вращает «Винт».

## Сцена 5 — ИДЗ «Дом»

- **Стены** «Стены дома (Wall)» → «Модификаторы»:
  1. «Винт» с «Углом» 0 → поле «Винт» = **Height** 3 (попробуй 4 — стены выше);
  2. «Объёмность» → «Толщина» = **Width** 0,3, «Смещение» = **Justification** (−1 / 0 / 1);
  3. «Логический» → «Разница» с коллекцией «Проёмы — вырезы…» (дыры под двери и окна). Выключи его — проёмы исчезнут.
- Tab на стенах — виден только контур из 4 рёбер: это как линия, которую рисуешь инструментом Wall.
- **Дверь** (Pivot Door): выдели пустышку «Дверь — петля» → R Z → дверь открывается/закрывается (= Open).
- **Окна**: глухое, распашное (петля, 35°), среднеповоротное (ось, 25°), раздвижное (створка сдвинута на 40 %). У створок — свои пустышки-петли, их можно крутить.
- **Лестница** — ступень + «Массив» («Количество» 3, «Относительное смещение» 0 / 1 / 1). Поставь 5 — ступеней больше.
- **Деревья** → модификатор «Дерево (Foliage)»: Высота, Плотность кроны, Обрезка снизу, **Вариация (Seed)**, Листва, Ствол. Покрути «Вариацию» — новое дерево (как кнопка New в 3ds Max). Образцы с разными параметрами — в скрытой коллекции.
- **Изгородь** — выдели «Путь изгороди (Pick Railing Path)» → модификатор «Изгородь (Railing)»: Высота, Шаг столбов, Шаг штакетника, **Сплошной щит (Solid Fill)**. Tab → двигай точки пути — забор идёт за ними.

## Если спросят «почему»

- **Почему нет Tube / Damper / Spring / Wall / Foliage?** В Blender их просто нет. Есть дополнения (Archimesh — стены, двери, окна, лестницы; Sapling Tree Gen — деревья), но они ставятся отдельно; файл сделан без них, чтобы открывался везде.
- **Почему пружина не «плывёт», когда двигаешь груз?** Высота витка считается драйвером: расстояние ÷ число витков. А поворот к грузу даёт «Слежение с амортизацией».
- **Почему у тора удалена половина?** У тора Blender нет Slice, иначе ручка торчала бы внутрь чашки.
- **Чем Quad отличается от Tri?** Подразделение (Кэтмулл-Кларк) делит четырёхугольник на 4 ровных, а треугольник — на 3 неровных четырёхугольника, поэтому поверхность из треугольников сглаживается с перекосом.
- **Что такое Editable Patch в Blender?** Ближе всего — NURBS-поверхность или меш в режиме редактирования. Параметры примитива в Blender есть только сразу после создания (панель в левом нижнем углу); дальше — только правка вершин. Это как переход Patch Grid → Editable Patch.
- **Почему проёмы не делаются сами?** В Blender двери и окна — обычные объекты, они не знают про стену. Дыру режет модификатор «Логический».

## Если попросят сделать вживую

1. **Труба:** Shift+A → Меш → Цилиндр → панель слева внизу: «Тип заполнения оснований» = «Ничего» → «Модификаторы» → Добавить модификатор → Генерировать → «Объёмность» → «Толщина» 0,3.
2. **Пружина:** Shift+A → Меш → Окружность («Радиус» 0,1) → R X 90 → Tab, G X 1, Tab → Добавить модификатор → «Винт» → «Итераций» 5, «Винт» 0,5.
3. **Сглаживание сетки:** Shift+A → Меш → Сетка → Ctrl+2 (быстро добавляет «Подразделение поверхности», 2 уровня).
4. **Стена:** Shift+A → Меш → Плоскость → Tab, удалить всё, кроме одного ребра → «Винт» с углом 0 (поле «Винт» = высота) → «Объёмность» (толщина). Потом удали всё (X).
