# Шпаргалка к защите — Лаба 5 (Blender)

## Как устроен файл

- `Лаба5_Blender.blend`, одна сцена «Шестерёнки». Коллекции в аутлайнере:
  - «Шестерёнка 1 (ведущая)» — «Кольцо 1» (бронза) и «Диск 1» (дерево);
  - «Шестерёнка 2» — «Кольцо 2» (серебро) и «Диск 2» (дерево);
  - «Камера и свет» — камера и два «Солнца»;
  - «Этапы шестерёнки (скрыто)» — кольцо, кольцо + диск, грани после выдавливания, кольцо с зубьями. Включаются глазом. Стоят в ряд за шестерёнками (по Y = 300).
- Анимация — кадры 0–100. **Пробел** — воспроизвести, ещё раз пробел — стоп. Shift+← — в начало.
- Движок в файле — EEVEE, F12 даёт кадр сразу. Видео: Ctrl+F12, файл появится рядом с .blend.
- Если при открытии Blender спросит про Auto Run Python Scripts — можно не разрешать: все драйверы «простые», работают и так.
- Сломал что-то — Ctrl+Z.

## Цвета полей (спросят обязательно)

- **Жёлтое / зелёное** поле — есть ключи (жёлтое — ключ на этом кадре). Это «Вращение Z» у «Кольца 1».
- **Фиолетовое** поле — драйвер (связанный параметр). Это «Вращение Z» у «Диска 1», «Кольца 2», «Диска 2».

## Модель

- Выдели «Кольцо 1» → **Tab** → видно 24 стороны и 24 зуба. Клавиша 3 — режим граней. Tab — выйти.
- **Edged Faces** = «Наложения» → «Каркас» (в файле уже включено).
- Включи глаз у этапов и покажи по порядку: кольцо → диск → «столбики» после выдавливания → зубья.
- Как сделаны зубья: Alt+щелчок по наружной грани (кольцо граней) → Alt+E «Экструдировать отдельные грани» на 12 → «Центр трансформации» = «Индивидуальные ориджины» → S 0.15.
- Кнопка **Ring** = Ctrl+Alt+щелчок по ребру («Выделить → Выделить петли → Кольца рёбер»). Покажи на «Этап 1» в режиме рёбер (клавиша 2).
- Вторая шестерёнка: X = 154 (N → «Элемент» → «Положение»).

## Драйверы (Wire Parameters)

- Выдели «Кольцо 2» → N → «Элемент» → ПКМ по фиолетовому «Вращение Z» → **«Редактировать драйвер»**:
  - тип «Скриптовое выражение», выражение `-var + radians(7.5)`;
  - переменная `var`, тип «Одно свойство», объект «Кольцо 1», путь `rotation_euler[2]`.
- Убери минус (`var + radians(7.5)`) → пробел: колёса крутятся в одну сторону и зубья проходят друг сквозь друга. Верни минус.
- Убери `+ radians(7.5)` → зуб упирается в зуб. Верни.
- Все драйверы сразу: тип редактора (временная шкала внизу) → «Драйверы».
- Поверни «Кольцо 1» вручную (R Z) на кадре без ключа — всё крутится за ним. Потом Ctrl+Z.
- Попробуй повернуть «Диск 1» — не выйдет: поле под драйвером. Это ответ на «где обоюдная связь».

## Ключи

- Выдели «Кольцо 1»: на временной шкале ромбики на кадрах 0, 24, 41, 71, 100. Углы: 0°, 120°, 60°, 240°, 180°. Между 24 и 41 угол уменьшается — колёса крутятся назад.
- Кнопка с кружком на шкале — «Автосоздание ключей» (AutoKey).
- Ключ вручную: курсор над полем «Вращение Z» → **I**. Удалить ключ — Alt+I.
- График угла: тип редактора → «Редактор графов».

## Материалы и видео

- «Настройки материалов»: «Бронза», «Серебро» (Металлик 1), «Дерево» (узлы: «Текстура волны» → «Градиентная карта»). Поменять под задание преподавателя: выдели кольцо → в списке материалов выбери другой из выпадающего списка.
- Видео: вкладка «Настройки вывода файлов» → «Вывод»: «Тип носителя» Видео, «Формат файла» «Видео FFmpeg»; «Кодирование»: «Контейнер» AVI, «Видеокодек» MPEG-4, «Качество вывода» — «Постоянный битрейт», «Битрейт» 6000. Ctrl+F12.

## Если спросят «почему»

- **Почему нет Tube?** В Blender нет такого примитива. Кольцо = окружность без заполнения → E + S → E по Z.
- **Почему не выдавливание рёбер?** В Blender ребро выдавливается в плоскую «ленту», зуба не получится. Выдавил грани и сжал — форма та же.
- **Почему 154, а не 150?** 70 (основание) + 81,4 (вершина зуба) ≈ 151,4, плюс зазор, чтобы зубья не проходили друг сквозь друга. При 152 уже задевают — проверено расчётом.
- **Почему 7,5°?** Шаг зубьев 360/24 = 15°. Половина шага ставит зуб одного колеса напротив впадины другого.
- **Почему radians()?** Blender хранит углы в радианах, а в полях показывает градусы.
- **Почему минус?** Сцепленные шестерёнки вращаются в разные стороны. При равном числе зубьев угол второй = −угол первой.
- **Почему нет <-->?** Драйвер работает в одну сторону: значение ведомого вычисляется, его нельзя менять руками. Иначе была бы петля.
- **Почему тип «Скриптовое выражение»?** После «Вставить драйвер» драйвер просто копирует значение (тип обычно «Усреднённое значение»). Чтобы написать минус и смещение, нужен тип «Скриптовое выражение». Имя переменной в выражении должно совпадать с именем в списке переменных (в файле — `var`).

## Если попросят сделать вживую

1. Shift+A → Меш → Куб, ещё один куб, сдвинь его G X 3.
2. Первый куб: N → «Элемент» → ПКМ по «Вращение Z» → «Копировать как новый драйвер».
3. Второй куб: ПКМ по «Вращение Z» → «Вставить драйвер». ПКМ → «Редактировать драйвер» → тип «Скриптовое выражение», в выражении поставь минус перед именем переменной (имя смотри ниже, в списке переменных).
4. Поверни первый куб (R Z) — второй вращается в обратную сторону. Потом удали кубы.
