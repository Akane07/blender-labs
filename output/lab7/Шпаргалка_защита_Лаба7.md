# Шпаргалка к защите — Лаба 7 (Blender)

## Как устроен файл

- `Лаба7_Blender.blend` — 8 **сцен** (переключаются справа вверху, поле «Сцена»). Они заменяют отдельные файлы .max из методички:

| Сцена | Задания | Аналог файла .max |
|---|---|---|
| 1 — Опорная точка | 1 | — |
| 2 — Перемещение, вращение, масштаб | 2 | ЛР_5.max, ЛР_7_1.max |
| 3 — Вестибюль | 3, 12, 13 | Вестибюль.max, Вестибюль01.max, Вестибюль02.max |
| 4 — Выравнивание ориентации | 4 | — |
| 5 — Копии и экземпляры | 5, 6 | — |
| 6 — Клонирование с выравниванием | 7 | — |
| 7 — Массивы | 11 | ЛР_7_2.max |
| 8 — ИДЗ «Архитектурный пейзаж» | ИДЗ | Фамилия_№группы_ИДЗ_7.max |

- После переключения сцены курсор на 3D-окно → **Home** (показать всё).
- В сценах есть скрытые коллекции «Этапы … (скрыто)» — объекты до изменения. Включаются глазом в аутлайнере.
- В каждой сцене своя камера и свет: F12 сразу даёт картинку.
- Размеры в метрах, как в методичке. Модификаторы (массивы, расстановка деревьев) не применены — их можно крутить.
- Сломал что-то — Ctrl+Z.

## Главные клавиши (спросят обязательно)

| Что | 3ds Max | Blender |
|---|---|---|
| Переместить | W, Select and Move | **G** |
| Повернуть | E, Select and Rotate | **R** (R R — свободно) |
| Масштаб | R, Select and Scale | **S** |
| По одной оси | F5, F6, F7 | после G/R/S: **X**, **Y**, **Z** |
| В плоскости | F8 | **Shift+X / Shift+Y / Shift+Z** |
| Точное значение | F12 Transform Type-In | число после клавиши (G X 0.5) или боковая панель **N** |
| Копия | Shift + перетаскивание, Copy | **Shift+D** |
| Экземпляр | Instance | **Alt+D** |
| Выравнивание | Alt+A | Объект → Трансформировать → Выровнять объекты |
| Зеркало | Mirror | **Ctrl+M** → ось |
| Каркас | F3 | **Z** → «Каркас» |
| Показать всё | Zoom Extents All | **Home** |

## Сцена 1 — опорная точка (ориджин)

- Выдели «Цилиндр 6 граней»: оранжевая точка ориджина стоит на **верхнем основании**.
- Как перенесли: «Опции» (правый верхний угол) → «Влиять только на: Ориджины» → G Z. Покажи вживую, потом сними флажок и Ctrl+Z.
- Отличие: у Blender ориджин нового цилиндра — в центре, у 3ds Max — внизу. Сравни с «Этапом» в скрытой коллекции.
- Покажи, зачем это нужно: R → цилиндр вращается вокруг верхнего основания.

## Сцена 2 — перемещение, вращение, масштаб

- «Пирамида (повёрнута на 90°)»: N → «Вращение» X = 90.
- «Шар 1 → диск»: «Масштаб» 1.4, 1.4, 0.2. «Шар 2 → торпеда»: 3, 0.5, 0.5.
- «Шар 3» — аналог **Squash**: модификатор «Простая деформация», метод «Растянуть». Покрути «Коэффициент» — шар вытягивается и одновременно худеет (объём сохраняется).
- **Центр трансформации** (меню рядом с магнитом): выдели 2–3 объекта, R, и переключай «Средняя точка» / «Индивидуальные ориджины» — видна разница. Потом Ctrl+Z.

## Сцена 3 — вестибюль

- Части: «Основание Box01» (1 × 1 × 0.18), «Цилиндр Cylinder01» (R 0.3, H 0.12), «Купол Sphere01» (R 0.5, обрезан на 80 %), портик: «Стойка Box02», «Стойка Box03», «Столб Box04», «Перекладина Box05». Размеры — N → «Размеры».
- **Выравнивание вживую:** включи этапы → выдели «Этап 1 — Цилиндр», Shift+щелчок по «Этап 1 — Основание» → Объект → Трансформировать → Выровнять объекты → слева внизу переключай «Режим выравнивания»: «Отрицательные стороны» / «Центр» / «Положительные стороны». Потом Ctrl+Z.
- Почему в два шага: Blender не умеет «низ одного к верху другого». Делаем «Положительные стороны» (верх к верху) + G Z на высоту объекта.
- **Задание 12 (деревья):** выдели «П-образный путь (Line)» → вкладка «Модификаторы» → «Расстановка по кривой (Spacing Tool)»: крути «Количество (Count)» — деревья перестраиваются. Tab на кривой → G по точке — деревья едут за кривой. Потом Ctrl+Z.
- **Задание 13 (зеркало):** коллекция «Портик — зеркальная копия»: у объектов «Масштаб» Y = −1 — так Blender хранит отражение. Выключи глаз у коллекции — копия исчезнет.

## Сцена 4 — ориентация

- Выдели оранжевый, Shift+щелчок по синему → N → ПКМ по «Вращение» → «Копировать всё на выделение». (В файле уже сделано; сравни с этапом.)
- Quick Align = Shift+S → «Выделенное к активному».

## Сцена 5 — копии и экземпляры

- Синие — **копии** (Shift+D): у каждой свой меш, менялись по отдельности.
- Оранжевые — **экземпляры** (Alt+D): вкладка «Данные объекта» → у меша цифра **3** (три пользователя).
- Покажи вживую: выдели «Экземпляр 1» → Tab → A → S → 1.5 → Tab — меняются все три. Потом Ctrl+Z.
- Select Dependents = Shift+L → «Данные объекта».
- Разорвать связь: Объект → Отношения → «Для одного пользователя».

## Сцена 6 — клонирование с выравниванием

- «Метка 1», «Метка 2» — пустышки (оси). «Клон 1», «Клон 2» стоят ровно по ним.
- Как: Shift+D → Esc → Shift+щелчок по метке → N → ПКМ «Положение» → «Копировать всё на выделение», то же для «Вращение».
- Подвинь метку и повтори — клон встанет по новому месту.

## Сцена 7 — массивы

- «Цилиндр — массив 10 × 2» → «Модификаторы»: два «Массива».
  - Первый: «Количество» 10, «Смещение по объекту» = пустышка «Шаг массива…».
  - Выдели пустышку: «Положение» X 0.6 (Move), «Вращение» X 10° (Rotate), «Масштаб» 0.9 (Scale 90 %). Подвигай её — весь ряд меняется.
  - Второй: «Количество» 2, «Постоянное смещение» Z −2 → второй ряд на 2 м ниже (2D).
- Свои варианты: круг из 12 кубов (пустышка повёрнута на 30°) и лестница («Относительное смещение» 0, 1, 1).

## Сцена 8 — ИДЗ

- Здание поставлено ярусами выравниванием, колоннада и фонари — «Массив», правое крыло и правая аллея — зеркальные копии, деревья — по кривой (геометрические ноды). F12 — финальный кадр.

## Если спросят «почему»

- **Почему нет параметров цилиндра после создания?** В Blender примитив сразу становится мешем; параметры есть только в панели операции сразу после создания. Дальше — режим редактирования (Tab).
- **Почему нет Hemisphere?** Нет такого параметра: низ сферы удалили вручную (Tab, выделить, X) и закрыли дыру (F).
- **Где Reference?** Нет в Blender. Ближе всего — Alt+D (общий меш) + свои модификаторы у каждого объекта.
- **Где Foliage?** Библиотеки деревьев нет — дерево собрано из конуса и икосферы.
- **Почему кривую не удалили после Spacing?** Она задаёт положение деревьев: исправишь кривую — деревья переставятся сами. На рендере её не видно.
- **Почему шаг массива уменьшается?** Масштаб пустышки 0.9 уменьшает и копию, и шаг к следующей.

## Если попросят сделать вживую

1. Shift+A → Меш → Цилиндр → в панели слева внизу «Вершины» 6.
2. Shift+D → X → 2 → Enter, затем Shift+R — две копии в ряд.
3. Выдели цилиндр → «Модификаторы» → Добавить модификатор → Генерировать → «Массив» → «Количество» 5.
4. Ctrl+M → Y — зеркальное отражение. Потом удали всё (X).
