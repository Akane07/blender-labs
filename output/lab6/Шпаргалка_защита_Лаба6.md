# Шпаргалка к защите — Лаба 6 (Blender)

## Как устроен файл

- `Лаба6_Blender.blend`, одна сцена «Космический пейзаж». Коллекции:
  - «Планета» — UV-сфера «Планета» (радиус 60, 60 сегментов, гладкое затенение);
  - «Светило» — «Светило — точечный источник» и «Светило — видимая сфера» (в той же точке);
  - «Камера»;
  - «Этапы (скрыто)» — сфера на 12 сегментов с ломаным контуром. Включается глазом (стоит там же, где планета: выключи глаз у «Планеты», чтобы её увидеть).
- Все картинки упакованы в файл. Рядом лежат и отдельными .png: `Звёздное_небо_2500x2500.png` (задание 1), `Звёздное_небо_6000x3000.png` (для окружения), `Планета_2048x1024.png`.
- Движок — EEVEE: F12 сразу даёт картинку с бликами. Окно проекции — в режиме «Предпросмотр материала» со звёздным фоном.
- Сломал что-то — Ctrl+Z.

## Задание 1 — текстура неба

- Честно: картинка собрана скриптом (Python) по шагам методички: шум 10 % → «Уровни» → цветные пятна → «Размытие по Гауссу» 60 → «Скручивание» → слой в режиме «Экран», 55 %. В отчёте шаги описаны как шаги Photoshop.
- Если преподаватель попросит показать в Photoshop (или бесплатно в Photopea, photopea.com — меню те же), 10 минут:
  1. Файл → Создать: 2500 × 2500, 72 пикс/дюйм, фон белый. Редактирование → Выполнить заливку → Чёрный.
  2. Фильтр → Шум → Добавить шум: 10 %, «По Гауссу», «Монохромный».
  3. Изображение → Коррекция → Уровни (Ctrl+L): левый ползунок ≈ 64, правый ≈ 102.
  4. Слой → Новый → Слой. Мягкая большая кисть, разные цвета — нащёлкать пятна.
  5. Фильтр → Размытие → Размытие по Гауссу: 60. Фильтр → Искажение → Скручивание: ≈ 120°.
  6. В панели слоёв: режим «Экран», «Непрозрачность» 55 %. Файл → Экспортировать → PNG.
  - Делай скриншоты после шагов 2, 3, 5, 6 — ими можно заменить рис. 1–6 отчёта.

## Окружение (звёздное небо)

- Вкладка с красным глобусом «Настройки мира» → «Поверхность»: «Фон» ← «Текстура окр. среды», проекция «Равнопромежуточная» (аналог Spherical Environment).
- Почему 6000 × 3000, а не квадрат: равнопромежуточная проекция = 360° × 180°, то есть 2 : 1. Квадратная растянется вдвое по горизонтали. Покажи: в узле выбери картинку `Звёздное_небо_2500x2500` — звёзды станут вытянутыми. Потом верни.
- Viewport Background = «Шейдинг вьюпорта» → «Предпросмотр материала» + флажок «Окружение сцены» (меню-стрелка справа вверху). Вращай вид — фон меняется.

## Планета

- Выдели «Планета» → вкладка «Настройки материалов» или вкладка «Шейдинг» вверху — видны узлы.
- **Рельеф (Bump):** узел «Карта неровностей»: «Сила» 0,5 (= Bump 50), «Расстояние» 1,5. Поставь «Силу» 0 → F12 — кратеры на границе света и тени стали плоскими. Верни.
  - Почему «Расстояние» 1,5, а не 0,001: планета радиусом 60 — огромная, при 0,001 рельефа не видно.
- **Self-Illumination + Mask + Falloff = красный ободок:**
  - «Вес слоя» (Френель) → «Градиентная карта» чёрный → красный — это Falloff Fresnel;
  - «Текстурные координаты» (объект — светило) → «Масштаб −1» → «Нормализовать» → «Скалярное произведение» с нормалью → «Отобразить диапазон» — это Falloff Shadow/Light: свет белый, тень чёрная;
  - «Инвертировать» — это Invert Mask; «Смешать цвета» (Умножение) — это Mask.
  - Отключи «Инвертировать» (выдели → M) — ободок переедет на освещённую сторону. Верни (M ещё раз).
- Сегменты: на сфере из «Этапов» видно, почему 60: при 12 контур ломаный.
- Если найдётся оригинальная текстура планеты: в узле «Текстура изображения» нажми значок папки и выбери файл. Чтобы она сохранилась в .blend: Файл → Внешние данные → Упаковать ресурсы.

## Свет

- «Светило — точечный источник» → вкладка с зелёной лампочкой: «Мощность» 7 000 000 Вт, «Радиус» 8.
  - Почему такая мощность: до планеты ≈ 380 единиц, яркость падает как 1/расстояние².
  - Поставь «Радиус» 0 → граница тени станет резкой. Это и есть «мягкие тени» mr Area Omni.
- Сам точечный источник на рендере не виден, поэтому в его точке — «Светило — видимая сфера» с излучением 40. У сферы выключена «Тень» (Свойства объекта → Видимость), иначе она закрыла бы свет источника внутри себя.

## Блики (Lens Effects)

- Вкладка «Композитинг» вверху: «Рендер-слои» → 4 узла «Блики» → «Выходы группы».
  - «Туманное свечение» = Glow (Size 180, Intensity 110);
  - «Призраки» = Auto Secondary (цветные кружки на линии через центр кадра);
  - «Свечение» = второй Glow (Size 50);
  - «Полосы», 16 штук = Star (Qty 16).
- Выдели узел → M — эффект выключится (повтор M — включится). F12 — смотри разницу.
- Interactive = «Шейдинг вьюпорта» → «Композитор» = «Камера» (в файле включено): нажми 0 на цифровой клавиатуре (вид из камеры) — блики видны прямо в окне.
- Pick Light не нужен: «Блики» действуют на всё, что ярче «Порога», а ярче всего — светило.

## Сравнение визуализаторов (п. 18)

- «Настройки рендера» → «Рендер-движок»: EEVEE (в файле) ↔ Cycles. F12 в каждом. Cycles дольше, но тени и свет точнее. Блики одинаковые — это композитинг.

## Если спросят «почему»

- **Где mental ray?** В Blender его нет. Аналог — Cycles.
- **Почему эффекты не в настройках рендера?** В Blender они делаются композитингом — обработкой уже готовой картинки.
- **Почему один узел картинки идёт и в цвет, и в рельеф?** Это аналог Paste (Instance): одна и та же карта, а не копия.
- **Почему нет Real-World Map Size?** У UV-сферы своя развёртка 0…1, картинка ложится на всю сферу сама.
- **Почему «Размер» у бликов 0,9, а не 180?** В Blender размер — доля кадра (0…1), а не пиксели.

## Если попросят сделать вживую

1. Shift+A → Меш → UV-Сфера → в панели слева внизу «Сегменты» 8 → контур ломаный; поставь 60 → ПКМ → «Гладкое затенение».
2. Shift+A → Свет → «Точечный источник» → вкладка лампочки: «Мощность» побольше, «Радиус».
3. Вкладка «Композитинг» → Shift+A → Фильтр → «Блики», вставь между «Рендер-слоями» и выходом → «Тип» «Полосы», «Полосы» 16 → F12.
4. Потом удали новые объекты и узел (X).
