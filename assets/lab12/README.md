# Исходный вестибюль для лабораторной 12

`Вестибюль02_ЛР7.blend` содержит только сцену `3 — Вестибюль (задания 3, 12, 13)` из пользовательского файла лабораторной 7. В отчёте ЛР7 итог с зеркальным портиком обозначен как аналог `Вестибюль02.max`. Пользователь разрешил использовать этот источник для ЛР12.

Сохранены исходные меши, преобразования, материалы, два источника «Солнце», земля, скрытые этапы и геометрические ноды двенадцати деревьев вдоль П-образного пути. Остальные семь сцен исходного файла не переносились. Геометрия не создавалась заново и не исправлялась по предположениям.

SHA256 исходного пользовательского файла: `05fa2871f07af5385a988651ee2f77cc337021ffe24caec6bb4edf177e8ae07a`. Сам исходник на рабочем столе не изменён. У выделенного файла другой хеш, потому что в нём оставлена одна сцена и сохранено активное окно.

`scripts/lab12/build_lab12.py` читает этот файл, поэтому для повторной сборки доступ к исходной папке пользователя не требуется. `--source=...` используется только для повторного выделения сцены из исходного файла. Проверка мешей, матриц и экземпляров выполняется `verify_lab12.py`.
