# Шпаргалка к защите — Лаба 4 (Blender)

## Как устроен файл

- В `Лаба4_Blender.blend` три **сцены** — по одной на задание. Переключаются справа вверху, в поле «Сцена»:
  - «1 — Шестерёнка»
  - «2 — Зубная щётка»
  - «3 — Горшок с травой (самостоятельное)»
- После переключения сцены курсор на 3D-окно → Home, чтобы увидеть всё.
- У каждой сцены своя камера, свет и фон, так что F12 сразу даёт правильный рендер.
- В каждой сцене есть скрытая коллекция «Этапы … (скрыто)» с копиями модели на промежуточных шагах. Показывается значком глаза в аутлайнере.
- Дополнение Extra Curve Objects нужно только для создания новой звезды. Открывать файл можно без него.
- Сломал что-то — Ctrl+Z.

## Сцена 1 — шестерёнка

Объект «Шестерёнка» — это **кривая**, а не меш: звезда и 6 окружностей внутри одного объекта.
- **Tab** — видно звезду и окружности как линии, это сплайны. Tab ещё раз — выйти.
- **Вкладка с зелёной кривой:**
  - «Форма» → 2D, «Режим заполнения» = «С двух сторон». Внутренние окружности из-за этого стали отверстиями.
  - «Геометрия» → «Экструдировать» = 2. Покрути: шестерёнка станет толще или тоньше. Толщина = 2 × значение, поэтому 2 даёт 4 (как Amount 4).
- **Материал «Позолота»:** «Металлик» 1. Поставь 0 — станет жёлтым пластиком; объяснение: золото = металл, блики окрашены в цвет металла. Верни 1.
- **Свет:** три «Солнца». Выключи одно глазом → F12 — видно, как меняются блики. Это ответ на вопрос «зачем свет для позолоты».
- **Показать Attach вживую:** Добавить → Кривая → Окружность → S → 5 → Enter → G, поставь её на сплошное место между отверстиями (не в дырку) → выдели окружность, потом Shift+щелчок по шестерёнке → Ctrl+J — появилось новое отверстие. Потом Ctrl+Z.

## Сцена 2 — зубная щётка

- **«Ручка»** — меш с модификатором «Сглаживание (MeshSmooth)».
  - Выключи модификатор значком монитора — видна угловатая исходная форма.
  - Tab — видно полигоны; Alt+щелчок по ребру — петля (аналог Loop).
- **Этапы (глаз у «Этапы щётки (скрыто)»):** линия → линия с прямоугольным сечением → выдавленная головка → площадка → декор → ряд из 8 цилиндров («Массив»: покрути «Количество»).
- **Профиль сечения:** объект «Профиль 12×6» (коллекция «Профиль сечения») задаёт сечение «Этапа 2». Если включён глаз этапов, подвигай или отмасштабируй профиль (S) — сечение кривой меняется сразу. Это аналог Rendering → Rectangular (Length / Width).
- **«Основания щетины»** — 36 цилиндров в одном объекте, на нём система частиц «Щетина» (аналог Hair and Fur). Вкладка «Настройки частиц»:
  - «Излучение»: Число 7000, Длина волос 11.
  - «Потомки» → «Шероховатость»: Равномерная 0 (Frizz Root), Конечная точка 0.05 (Frizz Tip).
  - «Рендер» → «Тайминг» → «Случайный» 0.08 (Rand. Scale).
  - «Форма волос»: Диаметр Корень = Конец = 1 (Root Thick = Tip Thick).
  - «Группы вершин» → «Плотность» = «Верх пучков» — поэтому волосы растут только из верхушек (аналог Update Selection).
- **Показать, откуда растут волосы:** выдели «Основания щетины» → Tab → вкладка с зелёным треугольником → «Группы вершин» → «Верх пучков» → «Выделить» — подсветятся верхушки. Tab — выйти.
- **Style Hair:** режим (левый верхний угол) → «Редактирование частиц» → кисть «Расчёска», поведи по щетине. Потом Ctrl+Z и обратно в «Режим объекта».
- **Freeze:** «Ручка» → Свойства объекта (оранжевый квадрат) → «Видимость» → снять «Доступно для выделения». Щелчок по ручке больше её не выделяет. Верни флажок.

## Сцена 3 — горшок

- **«Горшок»** — это кривая-профиль с модификатором «Вращение профиля (Lathe)» (тип «Винт»).
  - Выключи модификатор монитором — останется одна линия профиля.
  - Tab → двигай точки профиля (G) — форма горшка меняется сразу. Это главное про сплайны.
- **«Земля»** — диск с системой частиц «Трава». Покрути «Длина волос», «Скопление», «Шероховатость».

## Если спросят «почему»

- **Почему нет Convert to Editable Spline?** Кривая в Blender всегда редактируемая (Tab).
- **Почему нет модификатора Extrude?** Толщина задаётся в самой кривой: «Геометрия → Экструдировать».
- **Почему «Экструдировать» 2, а не 4?** Blender выдавливает в обе стороны от плоскости: 2 + 2 = 4.
- **Почему нет отдельной карты Falloff / Raytrace?** Principled BSDF физически правильный: френелевское отражение в нём уже встроено.
- **Почему в «Числе» 7000, а волос меньше?** Частицы распределяются по всей поверхности, а группа вершин оставляет только те, что попали на верхушки.
- **Почему кривая без толщины не видна на рендере?** У неё нет поверхности — только линия. Это аналог выключенного Renderable.
- **Чем Shift+D отличается от Alt+D?** Shift+D — независимая копия (Copy), Alt+D — связанная: меняешь форму одной — меняются все (Instance).

## Если попросят сделать вживую

Новая сцена или новый файл, затем:
1. Добавить → Кривая → Curve Profiles → Star: Star points 50, Outer radius 50, Inner radius 45 — в панели слева внизу, сразу после создания.
2. Добавить → Кривая → Окружность, Радиус 7.
3. Выдели окружность, потом Shift+щелчок по звезде → Ctrl+J — появилось отверстие.
4. Вкладка с зелёной кривой → «Геометрия» → «Экструдировать» 2.
